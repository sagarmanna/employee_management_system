# Employee Management System

Full-stack employee management app with React, Express, Sequelize, MySQL, JWT auth, and employee CRUD.

## Run

Backend:

```bash
cd backend
npm run dev
```

Frontend:

```bash
cd frontend
npm run dev
```

Set the backend database values in `backend/.env`. The app accepts `DB_NAME`; it also supports the existing `DB_NMAE` typo for compatibility.
